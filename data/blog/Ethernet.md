物理層にながすデータフレーム〇〇

# 構造


| フィールド                                | サイズ (ビット) | 内容 (例)                                                             |
| ----------------------------------------- | --------------- | --------------------------------------------------------------------- |
| プレアンブル (Preamble)                   | 56              | `10101010` を7回繰り返し（クロック同期用）                          |
| スタートフレームデリミタ (SFD)            | 8               | `10101011`（フレーム開始を示す）                                    |
| 宛先MACアドレス (Destination MAC Address) | 48              | `00000000 00011010 00101011 00111100 01001101 01011110`             |
| 送信元MACアドレス (Source MAC Address)    | 48              | `00000000 00011011 00111010 01001100 01011101 01101110`             |
| EtherType / 長さフィールド                | 16              | `00001000 00000000`（IPv4: `0x0800`）                             |
| データペイロード (Data Payload)           | 368～12000      | 上位プロトコルのデータ（最小46バイト、最大1500バイト）                |
| パディング (Padding)                      | 可変            | 必要に応じて0で埋める（46バイト未満の場合）                           |
| フレームチェックシーケンス (FCS)          | 32              | CRCによるエラーチェック（例:`11001100 11110000 10101010 01010101`） |


1. **プレアンブル (Preamble)**: 7バイト（56ビット）。`10101010` を7回繰り返すことで、受信側のクロック信号を同期させる。
2. **スタートフレームデリミタ (SFD)**: 1バイト（8ビット）。`10101011` で、フレームの開始を通知。
3. **宛先MACアドレス (Destination MAC Address)**: 6バイト（48ビット）。受信デバイスのMACアドレス。例: `00:1A:2B:3C:4D:5E` は `00000000 00011010 00101011 00111100 01001101 01011110`。
4. **送信元MACアドレス (Source MAC Address)**: 6バイト（48ビット）。送信デバイスのMACアドレス。例: `00:1B:3A:4C:5D:6E` は `00000000 00011011 00111010 01001100 01011101 01101110`。
5. **EtherType / 長さフィールド**: 2バイト（16ビット）。上位プロトコルの識別またはペイロードの長さを示す。例: IPv4は `0x0800`、バイナリでは `00001000 00000000`。
6. **データペイロード (Data Payload)**: 46～1500バイト（368～12000ビット）。上位プロトコルのデータ（IPパケットなど）が含まれる。ペイロードが46バイト未満の場合は、パディングフィールドで0を追加して46バイトにする。
7. **パディング (Padding)**: ペイロードが46バイト未満の場合、46バイトにするために0で埋める。
8. **フレームチェックシーケンス (FCS)**: 4バイト（32ビット）。CRC（循環冗長検査）によるエラーチェックを行う。例: `11001100 11110000 10101010 01010101`。
